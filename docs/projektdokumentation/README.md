# Projektdokumentation

`renditeradar-projektdokumentation.pdf` ist die vollständige Projektdokumentation, 16 Seiten A4, im gleichen Aufbau wie die übrigen Projektdokumentationen: Deckel mit Kennzahlen, Kurzfassung, Ausgangslage, Funktionsumfang, Architektur mit Systembild, sechs technische Kernprobleme nach Problem, Lösung und Warum es zählt, Datenmodell, Nachweise, Einblicke vom Wireframe bis zur laufenden Seite, und die Übersicht der belegten Fähigkeiten.

`renditeradar-projektdokumentation.html` ist die Quelle des PDFs. Die Bilder stecken als Data-URI in der Datei. Das PDF entsteht aus ihr mit Chrome im Druckmodus, Kopf- und Fusszeilen mit Seitenzahlen werden danach eingefügt.

Daneben liegen die Bildschirmaufnahmen einzeln, für die Verwendung ausserhalb der Dokumentation.
