# Projektdokumentation

`renditeradar-projektdokumentation.html` ist die vollständige Projektdokumentation: Architektur, sechs technische Kernprobleme mit Ursache und Behebung, Datenmodell, ausgeführte Nachweise und Einblicke vom Wireframe bis zur laufenden Seite.

Die Bilder stecken als Data-URI in der Datei, sie ist deshalb ohne weitere Dateien vollständig. Im Browser öffnen und über die Druckfunktion als PDF sichern, das Seitenformat ist auf A4 eingestellt.

Daneben liegen die Bildschirmaufnahmen einzeln, für die Verwendung ausserhalb der Dokumentation.
